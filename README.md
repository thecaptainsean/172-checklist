# Bates Aviation — Cessna 172M Pilot Checklist

A free, interactive, offline-capable pilot checklist for the 1973 Cessna 172M Skyhawk, derived from the original Pilot Operating Handbook.

**Live site:** https://thecaptainsean.github.io/172-checklist/

## What it includes

- 18 normal-procedure sections from preflight through securing the aircraft
- 13 emergency-procedure sections derived from the POH
- Color-coded category bars (preflight, engine, departure, in-flight, emergency)
- Light, dark, and red night-vision display modes
- Five color palettes, four fonts, adjustable text size
- Full edit mode — rename sections, add/remove items, customize freely
- Sections collapsed on load for a clean checklist view
- Saves your tail number, checks, and preferences locally
- Works fully offline once loaded

## How to use

Visit the live site, tap to check items, or tap "Edit mode: ON" to customize. Your changes save automatically in your browser.

To get a Home Screen icon on iPad/iPhone: open the site in Safari, tap Share → "Add to Home Screen."
